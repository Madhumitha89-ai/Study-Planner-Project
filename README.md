# 📚 Study Planner

A simple and user-friendly web application designed to help students organize their academic tasks, plan study schedules, and track their learning progress.

## 🌐 Live Demo

**Study Planner Website:** https://madhumitha89-ai.github.io/Study-Planner-Project/

> Note: This is a temporary LocalTunnel link. It works only while your laptop server and tunnel are running. Replace it with your permanent GitHub Pages URL after deployment.

## ✨ Features

* Add and organize study tasks
* Enter subject names and due dates
* Track completed and pending tasks
* View task statistics
* Simple and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Task management and interactivity

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.

Alternatively, run a local server from the project directory:

```bash
python -m http.server 8000
```

Open `http://localhost:8000/index.html` in your browser.
